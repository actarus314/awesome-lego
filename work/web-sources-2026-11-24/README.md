# Web search of 24 November 2026: where each data item of an ideal brick notebook lives

Work files, removed before merging, like `work/inventory-2026-11-24/`. Four parallel web searches (about 40 readings each, community sources included) looked for the sources of each data item that a tool for choosing and buying an adult brick set would need, beyond this directory and its inventory.

- `consigne.md`: shared instructions given to the four searches (in French).
- `a-catalogue.json`: catalogue, barcodes, dimensions, retirement, cross-brand concordance.
- `b-montage-qualite.json`: build attributes, build time, quality, original or copy, after-sales service.
- `c-offres-livraison.json`: offers, affiliate feeds, shop reviews, customs and clearance fees.
- `d-accessoires-occasion.json`: per-set accessories, second-hand, collection.

Each entry gives the source, what it holds, access, terms read, coverage, freshness, whether it was read in the search (`verifie`) and the evidence. Entries are in French. The synthesis lives outside this repository (project document `claude/carnet-donnees.md`). Some sources found here may also be candidates for the directory.
