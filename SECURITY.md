# Security / Sécurité

**English.** Report a vulnerability (in the scripts, the workflows or the website) privately: **Security** tab → **Report a vulnerability**. Do not open a public issue. A malicious or compromised link in the list can be reported the same way.

**Français.** Signaler une faille (scripts, workflows ou site) en privé : onglet **Security** → **Report a vulnerability**. Ne pas ouvrir de ticket public. Un lien malveillant ou compromis dans la liste se signale de la même façon.
